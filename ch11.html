String — ข้อความ

ตัด ต่อ ค้น แปลง และจัดรูปแบบข้อความ — งานที่โปรแกรมเกือบทุกตัวต้องทำ

11.1 String คือลำดับของตัวอักษร

ทุกอย่างที่ทำกับ list ในบทที่ 4 ใช้กับ string ได้เกือบหมด

s = "Python"
#     P  y  t  h  o  n
#     0  1  2  3  4  5
#    -6 -5 -4 -3 -2 -1

print(s[0])       # P
print(s[-1])      # n
print(s[0:3])     # Pyt
print(s[::-1])    # nohtyP  ← กลับด้าน
print(len(s))     # 6
print("th" in s)  # True

for ch in s:
    print(ch, end=".")     # P.y.t.h.o.n.

ดูเป็นภาพ · index และ slice ของ string

ใช้กฎเดียวกับ list ทุกอย่าง · กดปุ่มหรือพิมพ์เอง · ผลของ slice เป็น string ใหม่เสมอ

String แก้ไม่ได้ (immutable) เหมือน tuple:
s[0] = "J" → TypeError
ทุกคำสั่งที่ "เปลี่ยน" string จริง ๆ แล้วสร้าง string ใหม่เสมอ — ต้องรับค่ากลับมาเก็บ s = s.upper() ไม่ใช่แค่ s.upper() เฉย ๆ

11.4 เมธอดที่ใช้บ่อยที่สุด

เมธอดทำอะไรตัวอย่าง
.upper() .lower()เปลี่ยนตัวพิมพ์"Hi".upper() → HI
.strip()ตัดช่องว่างหัวท้าย" hi ".strip() → hi
.split(sep)แยกเป็น list"a,b".split(",") → ['a','b']
sep.join(list)รวม list เป็น string",".join(['a','b']) → a,b
.replace(a, b)แทนที่ข้อความ"cat".replace("c","b") → bat
.find(x)ตำแหน่งที่เจอ (ไม่เจอ = -1)"hello".find("ll") → 2
.count(x)นับจำนวนที่เจอ"banana".count("a") → 3
.startswith(x)ขึ้นต้นด้วย x ไหม"file.py".endswith(".py")
.isdigit()เป็นตัวเลขล้วนไหม"123".isdigit() → True
.title()ขึ้นต้นคำด้วยตัวใหญ่"a b".title() → A B
s = "abc" แล้วสั่ง s.upper() เฉย ๆ · s เป็นอะไร?
string แก้ไม่ได้ · เมธอดทุกตัวสร้างข้อความใหม่ ต้องรับค่ากลับมาเก็บ s = s.upper()

11.5 split และ join — คู่หูที่ใช้บ่อย

line = "ฟ้าใส,20,3.45"

parts = line.split(",")
print(parts)              # ['ฟ้าใส', '20', '3.45']

name, age, gpa = parts    # unpack ได้เลย
print(f"{name} อายุ {int(age)} เกรด {float(gpa):.2f}")

# split ไม่ใส่อะไร = แยกตามช่องว่าง (และตัดช่องว่างซ้ำให้ด้วย)
print("  hello   world  ".split())     # ['hello', 'world']

# join = ทำกลับด้าน
words = ["Python", "is", "fun"]
print(" ".join(words))    # Python is fun
print("-".join(words))    # Python-is-fun
join ใช้ได้กับ list ของ string เท่านั้น: ",".join([1, 2, 3]) จะ error
ถ้าเป็นตัวเลขต้องแปลงก่อน: ",".join(str(n) for n in [1, 2, 3]) → 1,2,3

โจทย์ 1 — วิเคราะห์ข้อความ

รับประโยคจากผู้ใช้ แล้วพิมพ์: จำนวนตัวอักษรทั้งหมด, จำนวนคำ, ข้อความตัวพิมพ์ใหญ่ทั้งหมด, ข้อความกลับด้าน และจำนวนสระ (a, e, i, o, u)

▸ ดูเฉลย 
text = input("ประโยค: ").strip()

    if ch in "aeiou":
        vowels += 1

print("ตัวอักษร:", len(text))
print("จำนวนคำ:", len(text.split()))
print("ตัวใหญ่:", text.upper())
print("กลับด้าน:", text[::-1])
print("สระ:", vowels)

โจทย์ 2 — แยกข้อมูล CSV

มีข้อมูลนักศึกษาเป็น list ของ string:
data = ["ฟ้าใส,20,3.45", "นล,21,3.10", "อาร์ม,20,2.85"]
แยกแต่ละบรรทัดแล้วพิมพ์เป็นตารางจัดคอลัมน์สวย ๆ พร้อมบอกเกรดเฉลี่ยรวมของทุกคน

▸ ดูเฉลย 
data = ["ฟ้าใส,20,3.45", "นล,21,3.10", "อาร์ม,20,2.85"]

print(f"{'ชื่อ':<10}{'อายุ':>6}{'เกรด':>8}")
print("-" * 24)

total = 0
for line in data:
    name, age, gpa = line.split(",")
    total += float(gpa)
    print(f"{name:<10}{int(age):>6}{float(gpa):>8.2f}")

print("-" * 24)
print(f"{'เฉลี่ยรวม':<10}{total / len(data):>14.2f}")

โจทย์ 3 — ตรวจรหัสผ่าน

รับรหัสผ่านจากผู้ใช้ แล้วตรวจว่าผ่านเกณฑ์ครบไหม: ยาวอย่างน้อย 8 ตัว, มีตัวพิมพ์ใหญ่, มีตัวพิมพ์เล็ก, และมีตัวเลข ถ้าไม่ผ่านให้บอกว่าขาดข้อไหน แล้ววนถามใหม่จนกว่าจะผ่าน

▸ ดูเฉลย 
while True:
    pw = input("ตั้งรหัสผ่าน: ")

    has_upper = False
    has_lower = False
    has_digit = False

    for ch in pw:
        if ch.isupper():
            has_upper = True
        elif ch.islower():
            has_lower = True
        elif ch.isdigit():
            has_digit = True

    problems = []
    if len(pw) < 8:   problems.append("ต้องยาวอย่างน้อย 8 ตัว")
    if not has_upper: problems.append("ต้องมีตัวพิมพ์ใหญ่")
    if not has_lower: problems.append("ต้องมีตัวพิมพ์เล็ก")
    if not has_digit: problems.append("ต้องมีตัวเลข")

    if not problems:
        print("รหัสผ่านผ่านเกณฑ์")
        break

    for p in problems:
        print(" -", p)

โจทย์ 4 — ท้าทาย: ตรวจ palindrome

รับข้อความ แล้วบอกว่าเป็น palindrome ไหม (อ่านหน้าหลังเหมือนกัน) โดยต้องไม่สนใจตัวพิมพ์เล็กใหญ่ ช่องว่าง และเครื่องหมายวรรคตอน
เช่น "A man, a plan, a canal: Panama" → เป็น palindrome

▸ ดูเฉลย 
text = input("ข้อความ: ")

# เก็บเฉพาะตัวอักษรกับตัวเลข แปลงเป็นตัวเล็กให้หมด
clean = ""
for ch in text.lower():
    if ch.isalnum():
        clean += ch

print("หลังทำความสะอาด:", clean)

if clean == clean[::-1]:
    print("เป็น palindrome")
else:
    print("ไม่เป็น palindrome")

โจทย์ 5 — วาด Flowchart

ตรวจรหัสผ่าน: ต้องยาวอย่างน้อย 8 ตัว และมีตัวเลขอย่างน้อย 1 ตัว ถ้าผิดข้อไหนให้บอกเหตุผลข้อนั้น วาด flowchart ก่อนเขียนโค้ด
