Chapter 05

Tuple — ทูเพิล

เหมือน list ทุกอย่าง ยกเว้นอย่างเดียว — สร้างแล้วแก้ไม่ได้

5.1 สร้าง Tuple

ใช้วงเล็บโค้ง ( ) แทนวงเล็บเหลี่ยม

point   = (10, 20)
rgb     = (255, 128, 0)
person  = ("ฟ้า", 20, "วิศวะ")
empty   = ()
one     = (42,)     # สมาชิกตัวเดียว ต้องมีจุลภาค!
กับดักตัวเดียว: (42) ไม่ใช่ tuple — Python มองว่าเป็นเลข 42 ในวงเล็บธรรมดา ต้องเขียน (42,) ถึงจะเป็น tuple
ลองเช็กด้วย type((42)) จะได้ int แต่ type((42,)) ได้ tuple

จริง ๆ แล้ววงเล็บใส่หรือไม่ใส่ก็ได้ ตัวที่ทำให้เป็น tuple คือจุลภาค

t = 1, 2, 3
print(t)         # (1, 2, 3)
print(type(t))   # <class 'tuple'>

5.2 อ่านค่าเหมือน List เป๊ะ

colors = ("red", "green", "blue", "yellow")

print(colors[0])     # red
print(colors[-1])    # yellow
print(colors[1:3])   # ('green', 'blue')
print(len(colors))   # 4
print("red" in colors)  # True
print(colors.count("red"))  # 1
print(colors.index("blue")) # 2

tuple มี method แค่ 2 ตัวคือ count() กับ index() — เพราะ method อื่น ๆ ของ list ล้วนเป็นการแก้ไข ซึ่ง tuple ทำไม่ได้

5.3 Immutable — แก้ไม่ได้

t = (1, 2, 3)
t[0] = 99
# TypeError: 'tuple' object does not support item assignment

t.append(4)
# AttributeError: 'tuple' object has no attribute 'append'

ถ้าอยากได้ค่าใหม่ ต้องสร้าง tuple ก้อนใหม่

t = (1, 2, 3)
t = t + (4,)      # (1, 2, 3, 4) → ก้อนใหม่ ไม่ใช่แก้ก้อนเดิม
t = t * 2         # (1,2,3,4,1,2,3,4)

5.4 List vs Tuple

ListTuple
เขียน[1, 2, 3](1, 2, 3)
แก้ไขได้ได้ (mutable)ไม่ได้ (immutable)
ความเร็วช้ากว่าเล็กน้อยเร็วกว่า กินหน่วยความจำน้อยกว่า
ใช้เป็น key ของ dictไม่ได้ได้
เหมาะกับข้อมูลที่จะเพิ่ม/ลบ/เรียงข้อมูลคงที่ เช่น พิกัด, สี RGB, ค่าคงที่
เลือกยังไง: ถามตัวเองว่า "ข้อมูลชุดนี้จะถูกแก้ทีหลังไหม"
จะแก้ → list · ไม่แก้ → tuple
การใช้ tuple เป็นการบอกคนอ่านโค้ดว่า "ห้ามแตะ" และกัน bug จากการเผลอแก้ได้ด้วย

แปลงไปมาได้ตลอด

a = [1, 2, 3]
t = tuple(a)     # (1, 2, 3)
b = list(t)      # [1, 2, 3]

# เทคนิค: อยากเรียง tuple ก็แปลงไป-กลับ
t = (3, 1, 2)
t = tuple(sorted(t))   # (1, 2, 3)

5.5 Unpacking — จุดเด่นของ Tuple

แตกค่าใน tuple ออกเป็นตัวแปรหลายตัวพร้อมกันในบรรทัดเดียว

point = (10, 20)
x, y = point
print(x, y)      # 10 20

person = ("ฟ้า", 20, "วิศวะ")
name, age, major = person
print(f"{name} อายุ {age} เรียน{major}")
จำนวนต้องเท่ากัน: tuple มี 3 ตัวแต่รับ 2 ตัวแปรจะได้ ValueError: too many values to unpack

เทคนิคที่ใช้บ่อยมาก — สลับค่าตัวแปร ทำได้ในบรรทัดเดียว ไม่ต้องมีตัวแปรพักเหมือนภาษาอื่น

a, b = 1, 2
a, b = b, a
print(a, b)      # 2 1

ฟังก์ชันคืนค่าหลายค่าก็คือคืน tuple นั่นเอง

def min_max(nums):
    return min(nums), max(nums)     # คืน tuple

lo, hi = min_max([4, 9, 2, 7])
print(lo, hi)    # 2 9

ถ้าไม่อยากได้บางค่า นิยมใช้ _ เป็นตัวแปรทิ้ง

name, _, major = ("ฟ้า", 20, "วิศวะ")   # ไม่สนใจอายุ

# ใช้ * รับที่เหลือทั้งหมด (เป็น list)
first, *rest = (1, 2, 3, 4, 5)
print(first)     # 1
print(rest)      # [2, 3, 4, 5]

5.6 กับดัก: tuple ที่มี list อยู่ข้างใน

tuple "แก้ไม่ได้" หมายถึงแก้ว่ามันชี้ไปที่อะไรไม่ได้ — แต่ถ้าสิ่งที่มันชี้ไปเป็น list ตัว list นั้นยังแก้ได้อยู่

t = (1, 2, [3, 4])
t[2].append(5)
print(t)         # (1, 2, [3, 4, 5])  ← เปลี่ยนได้!

t[2] = [9]       # TypeError  ← แต่เปลี่ยนตัวที่ชี้ไม่ได้

5.7 Flowchart กับ Tuple — unpacking ใช้กล่องเดียว

การ unpack หลายตัวแปรพร้อมกันเกิดขึ้นในบรรทัดเดียว จึงวาดเป็นกล่อง process กล่องเดียว เทียบกับการสลับค่าแบบเก่าที่ต้องใช้ตัวแปรพักถึง 3 กล่อง

# แบบซ้าย
temp = a
a = b
b = temp

# แบบขวา
a, b = b, a

แบบทดสอบ · เลือกตอบ

เลือกได้ข้อละครั้งเดียว คิดก่อนกด

ข้อใดสร้าง tuple ที่มีสมาชิกตัวเดียวได้ถูกต้อง?
ต้องมีจุลภาคท้าย ไม่งั้น (5) จะเป็นแค่เลข 5 ในวงเล็บ
โค้ดนี้เกิดอะไรขึ้น?
t = (1, 2, 3)
t[0] = 99
tuple เป็น immutable — TypeError: 'tuple' object does not support item assignment
a, b = 1, 2 แล้ว a, b = b, a — ผลคือ?
Python สร้าง tuple (b, a) ทางขวาก่อน แล้วค่อย unpack ลงซ้าย จึงสลับค่าได้ในบรรทัดเดียว
tuple มี method อะไรบ้าง?
มีแค่ 2 ตัวที่ไม่แก้ข้อมูล — method อื่นของ list ล้วนเป็นการแก้ไข
โค้ดนี้พิมพ์อะไร?
t = (1, 2, [3, 4])
t[2].append(5)
print(t)
tuple ห้ามเปลี่ยนว่าชี้ไปที่ก้อนไหน แต่ list ที่มันชี้อยู่ยังแก้ข้างในได้
ข้อมูลแบบใดควรเก็บเป็น tuple มากกว่า list?
พิกัดเป็นค่าคงที่ที่ไม่ควรถูกแก้ ส่วนอีก 3 ข้อต้องเพิ่ม/ลบ → ใช้ list
a, b = b, a วาดเป็นกล่อง process กี่กล่อง?
เป็นคำสั่งเดียวที่ทำพร้อมกัน จึงเป็นกล่องเดียว · แบบใช้ temp ถึงจะเป็น 3 กล่อง

แบบทดสอบ · เขียนโค้ด

โจทย์ 1 — ข้อมูลนักศึกษา

สร้าง tuple student เก็บ (รหัส, ชื่อ, สาขา, GPA) ของตัวเอง แล้ว unpack ออกมาเป็น 4 ตัวแปร พิมพ์ออกมาในรูปแบบประโยคด้วย f-string

▸ ดูเฉลย 
student = ("6510123", "ฟ้าใส", "วิศวกรรมคอมพิวเตอร์", 3.45)

sid, name, major, gpa = student
print(f"{name} รหัส {sid} สาขา{major} เกรดเฉลี่ย {gpa:.2f}")

โจทย์ 2 — ฟังก์ชันคืนหลายค่า

เขียนฟังก์ชัน stats(nums) รับ list ตัวเลข คืนค่า (ผลรวม, ค่าเฉลี่ย, ค่ามากสุด, ค่าน้อยสุด) เป็น tuple แล้วเรียกใช้พร้อม unpack

▸ ดูเฉลย 
def stats(nums):
    return sum(nums), sum(nums) / len(nums), max(nums), min(nums)

total, avg, hi, lo = stats([78, 95, 62, 88, 71])

print("รวม:", total)
print("เฉลี่ย:", round(avg, 2))
print("มากสุด:", hi)
print("น้อยสุด:", lo)

โจทย์ 3 — สลับและแปลง

กำหนด t = (5, 3, 9, 1, 7) ให้ทำ 3 อย่าง:

  1. พิมพ์ tuple ที่เรียงจากน้อยไปมาก (ผลลัพธ์ต้องยังเป็น tuple)
  2. แยกตัวแรกออกจากที่เหลือด้วย *
  3. สร้าง tuple ใหม่ที่ต่อเลข 100 ต่อท้าย
▸ ดูเฉลย 
t = (5, 3, 9, 1, 7)

print(tuple(sorted(t)))     # (1, 3, 5, 7, 9)

first, *rest = t
print(first, rest)          # 5 [3, 9, 1, 7]

t2 = t + (100,)
print(t2)                   # (5, 3, 9, 1, 7, 100)

โจทย์ 4 — ท้าทาย

มีข้อมูลร้านค้าเป็น list ของ tuple:
items = [("ข้าวผัด", 50), ("ชาเย็น", 25), ("ส้มตำ", 45)]
เขียนโปรแกรมพิมพ์ชื่อกับราคาทุกรายการ และบอกราคารวม (ใบ้: ใช้ for name, price in items: ซึ่งคือ unpacking นั่นเอง — รายละเอียดจะได้เรียนในบทถัดไป)

▸ ดูเฉลย 
items = [("ข้าวผัด", 50), ("ชาเย็น", 25), ("ส้มตำ", 45)]

total = 0
for name, price in items:       # unpack ทีละ tuple
    print(f"{name:10s} {price:3d} บาท")
    total = total + price

print("-" * 20)
print(f"{'รวม':10s} {total:3d} บาท")

โจทย์ 5 — วาด Flowchart

รับค่า x, y สร้างเป็น tuple point แล้ว unpack ออกมาเช็กว่าจุดอยู่ควอดรันต์ที่ 1 หรือไม่ วาด flowchart ก่อนเขียนโค้ด

▸ ดูเฉลย 
x = float(input("x: "))
y = float(input("y: "))
point = (x, y)
px, py = point
if px > 0 and py > 0:
    print("ควอดรันต์ 1")
else:
    print("ไม่ใช่ควอดรันต์ 1")
