Chapter 10

Set — เซต

กลุ่มข้อมูลที่ห้ามซ้ำ และไม่มีลำดับ — ตัดค่าซ้ำกับหาส่วนร่วมได้ในบรรทัดเดียว

10.1 สร้าง set

ใช้ปีกกาเหมือน dict แต่ใส่แค่ค่า ไม่มี key

fruits = {"apple", "banana", "cherry"}
nums   = {1, 2, 3, 4}

print(fruits)      # {'banana', 'cherry', 'apple'} ← ลำดับไม่แน่นอน
set ว่างต้องใช้ set(): เพราะ {} ถูกจองไว้ให้ dict ว่างไปแล้ว
type({}) → dict · type(set()) → set

ค่าซ้ำจะถูกตัดทิ้งอัตโนมัติ

s = {1, 2, 2, 3, 3, 3}
print(s)           # {1, 2, 3}
print(len(s))      # 3 ไม่ใช่ 6

10.2 ใช้งานจริงที่พบบ่อยที่สุด — ตัดค่าซ้ำ

nums = [3, 1, 4, 1, 5, 9, 2, 6, 5, 3]

unique = set(nums)
print(unique)              # {1, 2, 3, 4, 5, 6, 9}
print(len(unique))         # 7 → มีค่าไม่ซ้ำ 7 ตัว

# อยากได้ list กลับคืน (และเรียงด้วย)
print(sorted(set(nums)))   # [1, 2, 3, 4, 5, 6, 9]

ดูเป็นภาพ · set(nums) ตัดค่าซ้ำยังไง

ส่งตัวเลขจาก list เข้า set ทีละตัว · ตัวที่มีอยู่แล้วจะถูกปฏิเสธ

เทียบกับการเขียนเองด้วย list — set สั้นกว่ามาก

# วิธีเดิม
unique = []
for n in nums:
    if n not in unique:
        unique.append(n)

# วิธี set
unique = list(set(nums))

10.3 เพิ่ม ลบ เช็ก

s = {1, 2, 3}

s.add(4)           # {1, 2, 3, 4}
s.add(2)           # {1, 2, 3, 4} ← มีอยู่แล้ว ไม่มีอะไรเกิดขึ้น
s.remove(1)        # {2, 3, 4} ← ถ้าไม่มีจะเกิด KeyError
s.discard(99)      # ไม่มีก็ไม่ error (ปลอดภัยกว่า)
s.update([7, 8])   # เพิ่มทีละหลายตัว

print(3 in s)      # True
print(len(s))
set เช็ก in เร็วมาก: list ต้องไล่ดูทีละตัวจนเจอ แต่ set กระโดดไปหาได้เลย ถ้าต้องเช็ก "มีค่านี้ไหม" กับข้อมูลหลักหมื่นตัว set เร็วกว่า list หลายร้อยเท่า

10.4 การดำเนินการแบบเซต

a = {1, 2, 3, 4}
b = {3, 4, 5, 6}

print(a | b)    # {1,2,3,4,5,6}  union         — รวมทั้งสอง
print(a & b)    # {3, 4}         intersection  — เฉพาะที่มีทั้งคู่
print(a - b)    # {1, 2}         difference    — มีใน a แต่ไม่มีใน b
print(a ^ b)    # {1,2,5,6}      symmetric diff— มีข้างเดียวเท่านั้น

ดูเป็นภาพ · การดำเนินการแบบเซต

กดปุ่มคำสั่งด้านล่าง ส่วนที่เป็นผลลัพธ์จะถูกระบายสี

เขียนเป็นชื่อเต็มก็ได้ ความหมายเดียวกัน

สัญลักษณ์เมธอดความหมาย
a | ba.union(b)รวมกัน
a & ba.intersection(b)ส่วนร่วม
a - ba.difference(b)ผลต่าง
a ^ ba.symmetric_difference(b)ต่างสมมาตร
a <= ba.issubset(b)a เป็นสับเซตของ b

ตัวอย่างใช้จริง — เทียบรายชื่อสองวิชา

python = {"ฟ้า", "นล", "อาร์ม", "มิน"}
calculus = {"นล", "มิน", "เก้า"}

print("ลงทั้งสองวิชา:", python & calculus)     # {'นล', 'มิน'}
print("ลงอย่างน้อยหนึ่ง:", python | calculus)
print("ลง Python อย่างเดียว:", python - calculus)  # {'ฟ้า', 'อาร์ม'}

10.5 set ไม่มีลำดับ

s = {"c", "a", "b"}

print(s[0])        # TypeError: 'set' object is not subscriptable

เข้าถึงด้วย index ไม่ได้ เพราะไม่มีความคิดเรื่อง "ตัวแรก ตัวที่สอง" แต่วน loop ได้ตามปกติ

for x in s:
    print(x)       # ลำดับไม่รับประกัน

for x in sorted(s):
    print(x)       # a b c ← ถ้าต้องการลำดับ ให้ sorted ก่อน

10.7 Flowchart ตัดค่าซ้ำแต่คงลำดับเดิม

set(nums) ตัดค่าซ้ำได้ในกล่องเดียว แต่ลำดับหายไป ถ้าอยากเก็บลำดับเดิม ต้องใช้ set เป็น "สมุดจด" ว่าเคยเห็นค่าไหนแล้ว

seen = set()
result = []
for x in nums:
    if x in seen:
        continue
    seen.add(x)
    result.append(x)
print(result)

แบบทดสอบ · เลือกตอบ

เลือกได้ข้อละครั้งเดียว คิดก่อนกด

s = {1, 2, 2, 3, 3, 3} แล้ว len(s) เท่ากับ?
set ตัดค่าซ้ำอัตโนมัติ เหลือ {1, 2, 3}
type({}) คืออะไร?
{} คือ dict ว่าง — set ว่างต้องเขียน set()
a = {1,2,3}, b = {2,3,4} แล้ว a - b คือ?
ผลต่าง = มีใน a แต่ไม่มีใน b → เหลือแค่ 1 (ส่วน {1,4} คือ a ^ b)
อยากตัดค่าซ้ำใน list แล้วได้ list กลับคืน เขียนยังไงสั้นที่สุด?
แปลงเป็น set เพื่อตัดซ้ำ แล้วแปลงกลับเป็น list (ข้อสุดท้ายได้ set ไม่ใช่ list)
s = {"a","b","c"} แล้ว s[0] ได้อะไร?
set ไม่มีลำดับ จึงใช้ index ไม่ได้ — 'set' object is not subscriptable
a & b หมายถึงอะไร?
intersection — ส่วนร่วม ส่วนการรวมกันใช้ a | b
ตาม flowchart ตัดค่าซ้ำ (10.7) ถ้า nums = [3, 1, 3, 2, 1] จะได้ result เป็นอะไร?
3 กับ 1 ตัวหลังเคยเห็นแล้ว ทาง "จริง" พาข้ามไป · เหลือตัวที่เจอครั้งแรกตามลำดับเดิม

โจทย์ 1 — ตัดค่าซ้ำ

รับตัวเลขจากผู้ใช้ 8 ตัว (ใส่ทีละตัวด้วย for loop) แล้วบอกว่า มีเลขไม่ซ้ำกี่ตัว, เลขไม่ซ้ำมีอะไรบ้าง (เรียงจากน้อยไปมาก) และเลขไหนถูกใส่ซ้ำ

▸ ดูเฉลย 
nums = []
for i in range(1, 9):
    nums.append(int(input(f"เลขที่ {i}: ")))

unique = set(nums)
print("ไม่ซ้ำ", len(unique), "ตัว:", sorted(unique))

dup = set()
for n in unique:
    if nums.count(n) > 1:
        dup.add(n)

print("เลขที่ซ้ำ:", sorted(dup) if dup else "ไม่มี")

โจทย์ 2 — เทียบรายชื่อวิชา

กำหนด
python = {"ฟ้า","นล","อาร์ม","มิน"}
web = {"นล","มิน","เก้า","โบว์"}
พิมพ์: คนที่ลงทั้งสองวิชา, คนที่ลงอย่างน้อยหนึ่งวิชา (พร้อมจำนวน), คนที่ลง Python อย่างเดียว, และคนที่ลงวิชาเดียวเท่านั้น (ไม่ว่าวิชาไหน)

▸ ดูเฉลย 
python = {"ฟ้า", "นล", "อาร์ม", "มิน"}
web    = {"นล", "มิน", "เก้า", "โบว์"}

both = python & web
all_students = python | web

print("ลงทั้งสองวิชา:", sorted(both))
print(f"ลงอย่างน้อยหนึ่งวิชา {len(all_students)} คน:", sorted(all_students))
print("ลง Python อย่างเดียว:", sorted(python - web))
print("ลงวิชาเดียวเท่านั้น:", sorted(python ^ web))

โจทย์ 4 — ท้าทาย: เกมทายคำ

โปรแกรมเก็บคำลับไว้ 1 คำ (เช่น "python") ให้ผู้ใช้ทายทีละตัวอักษร ใช้ set เก็บตัวที่ทายไปแล้ว ถ้าทายซ้ำให้เตือน และจบเกมเมื่อทายครบทุกตัวอักษรของคำลับ พร้อมบอกว่าใช้ไปกี่ตา

▸ ดูเฉลย 
secret = "python"
target = set(secret)      # ตัวอักษรที่ต้องทายให้ครบ
guessed = set()
turn = 0

while True:
    ch = input("ทายตัวอักษร: ").lower()

    if ch in guessed:
        print("ทายตัวนี้ไปแล้ว")
        continue

    guessed.add(ch)
    turn += 1

    if ch in target:
        print("มีอยู่!", end=" ")
    else:
        print("ไม่มี", end=" ")

    # เหลือตัวที่ยังไม่ถูกทาย
    left = target - guessed
    print("เหลืออีก", len(left), "ตัว")

    if not left:
        print(f"ครบแล้ว! คำลับคือ '{secret}' ใช้ไป {turn} ตา")
        break
