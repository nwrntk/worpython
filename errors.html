คู่มืออ่าน error

error คือ Python บอกเราว่าพังตรงไหน เพราะอะไร · หน้านี้รวมวิธีอ่าน และกรณีจริงที่เจอบ่อย ข้อความ error ทุกอันได้จากการรันโค้ดจริงด้วย Python 3.13

ชนิด errorแปลคร่าว ๆเริ่มเจอ
SyntaxErrorเขียนผิดไวยากรณ์ Python อ่านไม่ออกบทที่ 1
IndentationErrorย่อหน้าผิดบทที่ 3
NameErrorไม่รู้จักชื่อนี้บทที่ 1
TypeErrorชนิดข้อมูลใช้กับคำสั่งนี้ไม่ได้บทที่ 2
ValueErrorชนิดถูก แต่ค่าใช้ไม่ได้บทที่ 2
ZeroDivisionErrorหารด้วยศูนย์บทที่ 2
IndexErrorตำแหน่งเกินขอบเขตบทที่ 4
KeyErrorไม่มี key นี้ใน dictบทที่ 9
AttributeErrorข้อมูลชนิดนี้ไม่มีเมธอด / คุณสมบัตินี้บทที่ 4
UnboundLocalErrorใช้ตัวแปรในฟังก์ชันก่อนจะมีค่าบทที่ 12
FileNotFoundErrorหาไฟล์ไม่เจอบทที่ 13
ModuleNotFoundErrorหาไลบรารีไม่เจอบทที่ 12
ไม่มี error แต่ผลผิดโปรแกรมทำตามที่เขียน แต่ไม่ใช่ที่ตั้งใจทุกบท

อ่าน Traceback 4 ขั้น

price = 120
qty = 3
total = price * qty + " บาท"
print(total)
Traceback (most recent call last):
  File "shop.py", line 3, in <module>         ← ② ไฟล์ไหน บรรทัดที่เท่าไร
    total = price * qty + " บาท"                ← ③ โค้ดบรรทัดนั้น
            ~~~~~~~~~~~~^~~~~~~~                ← ④ ^ ชี้จุดที่พังพอดี
TypeError: unsupported operand type(s) for +: 'int' and 'str'   ← ① อ่านบรรทัดนี้ก่อน
  1. อ่านจากล่างขึ้นบน บรรทัดสุดท้ายคือชนิด error กับเหตุผล · ที่นี่คือ TypeError เอา int มา + กับ str ไม่ได้
  2. ดู line 3 แล้วไปที่บรรทัดนั้นในโค้ด
  3. ดูเครื่องหมาย ^ ว่าชี้ตรงไหน · ที่นี่ชี้ +
  4. แก้ แล้วรันใหม่ · เช่น total = f"{price * qty} บาท"
แก้ทีละตัว แล้วรันใหม่ทุกครั้ง Python หยุดที่ error ตัวแรกที่เจอ บรรทัดหลังจากนั้นยังไม่ได้รันเลย แก้เสร็จอาจเจอ error ตัวถัดไป เป็นเรื่องปกติ
SyntaxError กับ IndentationError ไม่มีคำว่า Traceback เพราะโปรแกรมยังไม่ได้เริ่มรันเลยสักบรรทัด Python อ่านโค้ดไม่ออกตั้งแต่แรก · ถ้าหาที่ผิดในบรรทัดที่บอกไม่เจอ ให้ดูบรรทัดก่อนหน้าด้วย

error ที่มีหลายชั้น

ถ้า error เกิดในฟังก์ชัน Traceback จะมี File ... หลายก้อน กฎเดิม: อ่านจากล่างขึ้นบน ก้อนล่างสุดคือจุดที่พังจริง ก้อนบนคือทางที่เดินมาถึง

def average(nums):
    return sum(nums) / len(nums)

scores = []
print(average(scores))
Traceback (most recent call last):
  File "avg.py", line 5, in <module>           ← ถูกเรียกมาจากตรงนี้ (ต้นเหตุ: list ว่าง)
    print(average(scores))
          ~~~~~~~^^^^^^^^
  File "avg.py", line 2, in average             ← พังจริงตรงนี้
    return sum(nums) / len(nums)
           ~~~~~~~~~~^~~~~~~~~~~
ZeroDivisionError: division by zero

วลีที่เจอบ่อยในข้อความ error

ในข้อความมีคำว่าแปลว่า
was never closedเปิดวงเล็บ / เครื่องหมายคำพูด แล้วไม่ปิด
expected ':'ลืมโคลอนท้าย if / for / while / def
Perhaps you forgot a comma? · Did you mean ...?Python เดาให้แล้ว ลองตามที่มันแนะนำ
is not definedไม่มีชื่อนี้ สะกดผิด / ยังไม่ได้สร้าง / ลืมใส่คำพูด
unsupported operand · can only concatenateใช้ + - * / กับข้อมูลต่างชนิดกัน
not supported between instances ofเปรียบเทียบข้อมูลต่างชนิดกัน เช่น str กับ int
invalid literal for int()ข้อความนี้แปลงเป็นตัวเลขไม่ได้
out of rangeขอตำแหน่งที่ไม่มีอยู่จริง
has no attributeข้อมูลชนิดนี้ไม่มีเมธอดชื่อนี้ ดูชนิดที่อยู่หน้าคำนี้
'NoneType' object ...ตัวแปรเป็น None ย้อนไปดูว่าได้ค่านี้มาจากไหน
missing 1 required positional argumentเรียกฟังก์ชันโดยส่งค่าไม่ครบ
not subscriptable · does not support item assignmentใช้ [ ] กับข้อมูลที่ทำแบบนั้นไม่ได้

SyntaxError

เขียนผิดไวยากรณ์ Python อ่านไม่ออก · เริ่มเจอบทที่ 1

ลืมปิดวงเล็บ

print("สวัสดี"
print("ลาก่อน")
  File "main.py", line 1
    print("สวัสดี"
         ^
SyntaxError: '(' was never closed

สาเหตุ: เปิด ( แล้วไม่ปิด
แก้: ปิดวงเล็บให้ครบคู่ · Python ชี้ตัวที่เปิดค้างไว้ให้แล้ว

ลืมปิดเครื่องหมายคำพูด

print("สวัสดี)
  File "main.py", line 1
    print("สวัสดี)
          ^
SyntaxError: unterminated string literal (detected at line 1)

สาเหตุ: ข้อความเปิดด้วย " แต่ไม่มีตัวปิด
แก้: ใส่ " ปิดท้ายข้อความ

ลืมโคลอนท้าย if

score = 80
if score >= 50
    print("ผ่าน")
  File "main.py", line 2
    if score >= 50
                  ^
SyntaxError: expected ':'

สาเหตุ: บรรทัด if / for / while / def ต้องจบด้วย :
แก้: เติม : ตรงที่ ^ ชี้

ใช้ = แทน == ใน if

score = 80
if score = 100:
    print("เต็ม")
  File "main.py", line 2
    if score = 100:
       ^^^^^^^^^^^
SyntaxError: invalid syntax. Maybe you meant '==' or ':=' instead of '='?

สาเหตุ: = คือกำหนดค่า ส่วนการเปรียบเทียบต้องใช้ ==
แก้: เปลี่ยนเป็น if score == 100: · Python บอกให้แล้วใน "Maybe you meant '=='"

ลืมจุลภาคใน list

nums = [10 20, 30]
  File "main.py", line 1
    nums = [10 20, 30]
            ^^^^^
SyntaxError: invalid syntax. Perhaps you forgot a comma?

สาเหตุ: สมาชิกใน list ต้องคั่นด้วย ,
แก้: เป็น [10, 20, 30] · Python เดาให้แล้วว่า "forgot a comma"

IndentationError

ย่อหน้าผิด · เริ่มเจอบทที่ 3

ลืมย่อหน้าใต้ for

for i in range(3):
print(i)
  File "main.py", line 2
    print(i)
    ^^^^^
IndentationError: expected an indented block after 'for' statement on line 1

สาเหตุ: บรรทัดที่อยู่ใน loop / if ต้องย่อหน้าเข้าไป
แก้: ย่อหน้า print(i) เข้าไป 4 ช่อง

ย่อหน้าโดยไม่มีเหตุ

name = "ฟ้า"
    print(name)
  File "main.py", line 2
    print(name)
IndentationError: unexpected indent

สาเหตุ: บรรทัดธรรมดาที่ไม่ได้อยู่ใต้ if / for ห้ามย่อหน้า
แก้: ลบช่องว่างหน้าบรรทัดออก

ย่อหน้าไม่เท่ากัน

if True:
        print("a")
    print("b")
  File "main.py", line 3
    print("b")
              ^
IndentationError: unindent does not match any outer indentation level

สาเหตุ: บรรทัดแรกย่อ 8 ช่อง บรรทัดถัดไปย่อ 4 ช่อง ไม่ตรงกับระดับไหนเลย
แก้: ใช้ 4 ช่องเท่ากันทุกบรรทัด · อย่าผสม Tab กับ Space

NameError

ไม่รู้จักชื่อนี้ · เริ่มเจอบทที่ 1

สะกดชื่อตัวแปรผิด

name = "ฟ้า"
print(nmae)
Traceback (most recent call last):
  File "main.py", line 2, in <module>
    print(nmae)
          ^^^^
NameError: name 'nmae' is not defined

สาเหตุ: สร้าง name แต่เรียก nmae
แก้: เทียบตัวสะกดกับตอนสร้างทีละตัวอักษร

ลืมใส่เครื่องหมายคำพูด

print(สวัสดี)
Traceback (most recent call last):
  File "main.py", line 1, in <module>
    print(สวัสดี)
          ^^^^^^
NameError: name 'สวัสดี' is not defined

สาเหตุ: ไม่มีคำพูดครอบ Python จึงคิดว่า สวัสดี เป็นชื่อตัวแปร
แก้: print("สวัสดี")

สะกดชื่อฟังก์ชันผิด

pritn("hello")
Traceback (most recent call last):
  File "main.py", line 1, in <module>
    pritn("hello")
    ^^^^^
NameError: name 'pritn' is not defined. Did you mean: 'print'?

สาเหตุ: ไม่มีฟังก์ชันชื่อ pritn
แก้: Python เดาให้แล้ว "Did you mean: 'print'?"

ใช้ตัวแปรก่อนสร้าง

print(total)
total = 100
Traceback (most recent call last):
  File "main.py", line 1, in <module>
    print(total)
          ^^^^^
NameError: name 'total' is not defined

สาเหตุ: Python รันจากบนลงล่าง ตอนบรรทัด 1 ยังไม่มี total
แก้: ย้ายบรรทัดที่สร้างตัวแปรขึ้นไปก่อน

import แบบ from แล้วเรียกผ่านชื่อ module

from math import sqrt
print(math.sqrt(16))
Traceback (most recent call last):
  File "main.py", line 2, in <module>
    print(math.sqrt(16))
          ^^^^
NameError: name 'math' is not defined. Did you forget to import 'math'?

สาเหตุ: from math import sqrt นำเข้าแค่ sqrt ไม่ได้นำเข้าชื่อ math (บทที่ 12)
แก้: เรียก sqrt(16) ตรง ๆ หรือเปลี่ยนเป็น import math

TypeError

ชนิดข้อมูลใช้กับคำสั่งนี้ไม่ได้ · เริ่มเจอบทที่ 2

เอาค่าจาก input ไปบวกเลข

age = input("อายุ: ")
print(age + 1)
Traceback (most recent call last):
  File "main.py", line 2, in <module>
    print(age + 1)
          ~~~~^~~
TypeError: can only concatenate str (not "int") to str

สาเหตุ: input() ได้ str เสมอ แม้ผู้ใช้จะพิมพ์ตัวเลข
แก้: ครอบด้วย int() ตอนรับค่า

age = int(input("อายุ: "))
print(age + 1)

เอาตัวเลขไปต่อข้อความ

price = 120
print(price + " บาท")
Traceback (most recent call last):
  File "main.py", line 2, in <module>
    print(price + " บาท")
          ~~~~~~^~~~~~~~
TypeError: unsupported operand type(s) for +: 'int' and 'str'

สาเหตุ: บวก int กับ str ไม่ได้
แก้: ใช้ f-string

price = 120
print(f"{price} บาท")

เปรียบเทียบข้อความกับตัวเลข

score = input("คะแนน: ")
if score >= 50:
    print("ผ่าน")
Traceback (most recent call last):
  File "main.py", line 2, in <module>
    if score >= 50:
       ^^^^^^^^^^^
TypeError: '>=' not supported between instances of 'str' and 'int'

สาเหตุ: score เป็น str เทียบกับ 50 ที่เป็น int ไม่ได้
แก้: แปลงก่อน score = int(input("คะแนน: "))

หาความยาวของตัวเลข

n = 12345
print(len(n))
Traceback (most recent call last):
  File "main.py", line 2, in <module>
    print(len(n))
          ~~~^^^
TypeError: object of type 'int' has no len()

สาเหตุ: len() ใช้กับ str / list / dict ได้ แต่ไม่ใช่ int
แก้: len(str(n)) ถ้าอยากนับจำนวนหลัก

ส่งค่าเข้าฟังก์ชันไม่ครบ

def area(w, h):
    return w * h

print(area(5))
Traceback (most recent call last):
  File "main.py", line 4, in <module>
    print(area(5))
          ~~~~^^^
TypeError: area() missing 1 required positional argument: 'h'

สาเหตุ: area ต้องการ 2 ค่า (w, h) แต่ส่งมาค่าเดียว
แก้: area(5, 3) · ข้อความบอกชื่อพารามิเตอร์ที่ขาดให้ด้วย

แก้ตัวอักษรใน string

word = "cat"
word[0] = "b"
Traceback (most recent call last):
  File "main.py", line 2, in <module>
    word[0] = "b"
    ~~~~^^^
TypeError: 'str' object does not support item assignment

สาเหตุ: string แก้ไขไม่ได้ (immutable)
แก้: สร้างใหม่แทน word = "b" + word[1:]

ใช้ [ ] กับตัวเลข

n = 2026
print(n[0])
Traceback (most recent call last):
  File "main.py", line 2, in <module>
    print(n[0])
          ~^^^
TypeError: 'int' object is not subscriptable

สาเหตุ: int ไม่มีตำแหน่งให้ดึง
แก้: str(n)[0] ถ้าอยากได้หลักแรก

ValueError

ชนิดถูก แต่ค่าใช้ไม่ได้ · เริ่มเจอบทที่ 2

ผู้ใช้พิมพ์ตัวอักษร

n = int(input("จำนวน: "))
Traceback (most recent call last):
  File "main.py", line 1, in <module>
    n = int(input("จำนวน: "))
        ~~~^^^^^^^^^^^^^^^^^^
ValueError: invalid literal for int() with base 10: 'สิบ'

สาเหตุ: ข้อความ "สิบ" แปลงเป็น int ไม่ได้ · โค้ดไม่ผิด แต่ค่าที่ได้รับผิด
แก้: ตรวจก่อนด้วย .isdigit() (บทที่ 7) หรือดักด้วย try-except (บทที่ 13)

ผู้ใช้พิมพ์ทศนิยมใส่ int()

n = int(input("จำนวน: "))
Traceback (most recent call last):
  File "main.py", line 1, in <module>
    n = int(input("จำนวน: "))
        ~~~^^^^^^^^^^^^^^^^^^
ValueError: invalid literal for int() with base 10: '3.5'

สาเหตุ: int() แปลงข้อความ "3.5" ตรง ๆ ไม่ได้
แก้: ใช้ float() ถ้ายอมให้มีทศนิยม

ผู้ใช้กด Enter เฉย ๆ

n = int(input("จำนวน: "))
Traceback (most recent call last):
  File "main.py", line 1, in <module>
    n = int(input("จำนวน: "))
        ~~~^^^^^^^^^^^^^^^^^^
ValueError: invalid literal for int() with base 10: ''

สาเหตุ: ได้ข้อความว่าง '' ซึ่งไม่ใช่ตัวเลข
แก้: เช็กว่าว่างไหมก่อนแปลง หรือวน while จนกว่าจะได้ค่า

จำนวนตัวแปรไม่เท่าจำนวนค่า

a, b = [1, 2, 3]
Traceback (most recent call last):
  File "main.py", line 1, in <module>
    a, b = [1, 2, 3]
    ^^^^
ValueError: too many values to unpack (expected 2)

สาเหตุ: มี 3 ค่า แต่รับไว้ 2 ตัวแปร (บทที่ 5)
แก้: ให้จำนวนเท่ากัน a, b, c = [1, 2, 3]

ลบของที่ไม่มีใน list

nums = [1, 2, 3]
nums.remove(5)
Traceback (most recent call last):
  File "main.py", line 2, in <module>
    nums.remove(5)
    ~~~~~~~~~~~^^^
ValueError: list.remove(x): x not in list

สาเหตุ: remove หาค่า 5 ไม่เจอ
แก้: เช็กก่อน if 5 in nums: nums.remove(5)

ZeroDivisionError

หารด้วยศูนย์ · เริ่มเจอบทที่ 2

ตัวหารเป็น 0

total = 100
count = 0
print(total / count)
Traceback (most recent call last):
  File "main.py", line 3, in <module>
    print(total / count)
          ~~~~~~^~~~~~~
ZeroDivisionError: division by zero

สาเหตุ: หารด้วย 0 ไม่ได้ในคณิตศาสตร์
แก้: เช็กก่อน if count > 0:

หาค่าเฉลี่ยของ list ว่าง

scores = []
print(sum(scores) / len(scores))
Traceback (most recent call last):
  File "main.py", line 2, in <module>
    print(sum(scores) / len(scores))
          ~~~~~~~~~~~~^~~~~~~~~~~~~
ZeroDivisionError: division by zero

สาเหตุ: len([]) คือ 0
แก้: เช็ก if scores: ก่อนหาร (list ว่าง = เท็จ)

IndexError

ตำแหน่งเกินขอบเขต · เริ่มเจอบทที่ 4

ขอตำแหน่งเกินจำนวนสมาชิก

fruits = ["มะม่วง", "ส้ม", "กล้วย"]
print(fruits[3])
Traceback (most recent call last):
  File "main.py", line 2, in <module>
    print(fruits[3])
          ~~~~~~^^^
IndexError: list index out of range

สาเหตุ: มี 3 ตัว index คือ 0, 1, 2 ไม่มี 3
แก้: ตัวสุดท้ายใช้ fruits[-1] หรือ fruits[len(fruits) - 1]

ดึงตัวแรกจาก list ว่าง

queue = []
print(queue[0])
Traceback (most recent call last):
  File "main.py", line 2, in <module>
    print(queue[0])
          ~~~~~^^^
IndexError: list index out of range

สาเหตุ: list ว่างไม่มีแม้แต่ตำแหน่ง 0
แก้: เช็ก if queue: ก่อน

loop เกินไปรอบเดียว (off-by-one)

nums = [10, 20, 30]
for i in range(len(nums) + 1):
    print(nums[i])
Traceback (most recent call last):
  File "main.py", line 3, in <module>
    print(nums[i])
          ~~~~^^^
IndexError: list index out of range

สาเหตุ: range(len(nums) + 1) ให้ i = 0, 1, 2, 3 ซึ่ง 3 ไม่มี
แก้: ใช้ range(len(nums)) หรือดีกว่านั้น for n in nums:

ตำแหน่งเกินความยาว string

word = "cat"
print(word[5])
Traceback (most recent call last):
  File "main.py", line 2, in <module>
    print(word[5])
          ~~~~^^^
IndexError: string index out of range

สาเหตุ: "cat" มี 3 ตัว index สูงสุดคือ 2
แก้: เช็ก len(word) ก่อน

UnboundLocalError

  File "main.py", line 6, in <module>
    add()
    ~~~^^

    count += 1
    ^^^^^
UnboundLocalError: cannot access local variable 'count' where it is not associated with a value

สาเหตุ: ในฟังก์ชัน count += 1 ทำให้ Python ถือว่า count เป็นตัวแปรภายใน ซึ่งยังไม่มีค่า (บทที่ 12)
แก้: ส่งเข้า-คืนค่าแทน

count = 0

    return n + 1

count = add(count)

เช็กลิสต์เวลาเจอ error

  1. อ่านบรรทัดสุดท้าย: ชนิด error คืออะไร แล้วเปิดหาในหน้านี้
  2. ไปที่เลขบรรทัดที่บอก ดู ^ ว่าชี้ตรงไหน
  3. หาไม่เจอ? ดูบรรทัดก่อนหน้า (วงเล็บ / คำพูดที่ลืมปิด)
  4. ไม่แน่ใจว่าตัวแปรเป็นชนิดอะไร? print(type(x), x) ก่อนบรรทัดที่พัง
  5. แก้ทีละจุด แล้วรันใหม่ทุกครั้ง
