Chapter 15

pandas — ตารางข้อมูล

ข้อมูลจริงมาเป็นตารางที่มีหัวคอลัมน์ มีข้อความปน และมีช่องว่าง — pandas จัดการได้ในไม่กี่บรรทัด

15.1 ทำไมต้องมี pandas

NumPy เก่งเรื่องตัวเลขล้วน แต่ข้อมูลจริงมักมีหัวคอลัมน์ มีข้อความปน และมีช่องว่าง เช่น ไฟล์คะแนนนักเรียนหรือข้อมูลเซนเซอร์ที่มีวันที่ · pandas ทำให้จัดการตารางแบบนี้ได้ในไม่กี่บรรทัด

df = pd.read_csv("files/students.csv")

def grade(x):

    if x >= 70:
        return "B"
    if x >= 60:

    return "F"

แบบทดสอบ · เลือกตอบ

อ่านไฟล์ CSV เข้ามาเป็นตารางด้วยคำสั่งใด?
pandas มีตัวอ่านให้เลย และแยกคอลัมน์ พร้อมเดาชนิดข้อมูลให้อัตโนมัติ
df.head(3) ทำอะไร?
ใช้ดูหน้าตาข้อมูลอย่างรวดเร็วก่อนทำอย่างอื่น · tail() คือท้ายตาราง
ต่างกันอย่างไรระหว่าง df.loc[0] กับ df.iloc[0]?
ถ้า index เป็น 0,1,2 ตามปกติ ผลจะเหมือนกัน · แต่พอเปลี่ยน index เป็นชื่อคน จะต่างกันทันที
อยากได้คะแนนเฉลี่ยปลายภาคของแต่ละห้อง เขียนอย่างไร?
groupby แบ่งแถวเป็นกลุ่มตามค่าในคอลัมน์ แล้วสรุปทีละกลุ่ม
ช่องว่างในไฟล์ CSV กลายเป็นอะไรใน pandas?
NaN เป็นค่าพิเศษที่แปลว่า "ไม่มีข้อมูล" · เช็กด้วย isna() เทียบด้วย == NaN ไม่ได้
เขียน df.to_csv("out.csv") เฉย ๆ จะได้ไฟล์แบบไหน?
ค่าเริ่มต้นจะเขียน index ลงไปด้วย · ปกติไม่ต้องการ จึงใส่ index=False
