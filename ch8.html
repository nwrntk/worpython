8.5 Average — หาค่าเฉลี่ย

for value in [9, 41, 12, 3, 74, 15] :

print("After :", count, sum, "Average :", sum / count)

8.8 Largest — หาค่ามากที่สุด

เก็บ "ตัวที่มากที่สุดเท่าที่เจอมา" ไว้ในตัวแปร แล้วเทียบกับตัวใหม่ทุกรอบ

largest = -1
print('Before', largest)

for num in [3, 41, 12, 9, 74, 15] :
    if num > largest :
        largest = num
    print(largest, num)

print('After', largest)

# Before -1
# 3  3     ← 3 > -1 จริง เปลี่ยนเป็น 3
# 41 41    ← 41 > 3 จริง เปลี่ยนเป็น 41
# 41 12    ← 12 > 41 เท็จ ไม่เปลี่ยน
# 41 9
# 74 74
# 74 15
# After 74
largest = -1 ใช้ได้เฉพาะกับข้อมูลที่ไม่ติดลบ
ถ้าข้อมูลเป็น [-5, -3, -9] คำตอบจะออกมาเป็น -1 ซึ่งผิด เพราะ -1 ไม่ได้อยู่ในข้อมูลเลย — วิธีที่ถูกต้องคือใช้ None (หัวข้อถัดไป)

8.9 Smallest — หาค่าน้อยที่สุด และ None

คนมักคิดว่าแค่กลับเครื่องหมายจาก > เป็น < ก็พอ แต่จะพังทันที

# ผิด!
largest = -1
for num in [3, 41, 12, 9, 74, 15] :
    if num < largest :        # ไม่มีตัวไหนน้อยกว่า -1 เลย
        largest = num
    print(largest, num)
print('After', largest)

# -1 3
# -1 41
# ...
# After -1     ← ค่าเริ่มต้นไม่เคยถูกแทนที่

ทางแก้คือเริ่มด้วย None แล้วรับค่าแรกที่เจอมาเป็นค่าตั้งต้น

smallest = None
print('Before')

for value in [9, 41, 12, 3, 74, 15] :
    if smallest is None :
        smallest = value          # รอบแรก: รับค่าแรกมาเลย
    elif value < smallest :
        smallest = value
    print("smallest -", smallest, "value -", value)

print('After', smallest)

# Before
# smallest - 9 value - 9
# smallest - 9 value - 41
# smallest - 9 value - 12
# smallest - 3 value - 3
# smallest - 3 value - 74
# smallest - 3 value - 15
# After 3
None คือค่าพิเศษที่แปลว่า "ยังไม่มีค่า" ต่างจาก 0 หรือ "" ตรงที่ไม่ใช่ข้อมูลจริงเลย จึงเหมาะเป็นค่าตั้งต้นที่บอกว่า "ยังไม่เคยเจออะไร"
วิธีนี้ทำงานถูกต้องกับข้อมูลทุกแบบ รวมถึงเลขติดลบ

8.10 is และ is not

สังเกตว่าโค้ดข้างบนเขียน if smallest is None ไม่ใช่ == None

ตัวดำเนินการถามว่าใช้กับ
==ค่าเท่ากันไหมตัวเลข, ข้อความ, list ทั่วไป
isเป็นตัวเดียวกันเลยไหมNone, True, False
is notไม่ใช่ตัวเดียวกันเหมือนกัน แค่กลับผล
x = None

print(x is None)        # True   ← วิธีที่ถูกต้อง
print(x is not None)    # False

# กับตัวเลข ให้ใช้ == เสมอ
a = 1000
b = 1000
print(a == b)           # True  ← ค่าเท่ากัน
print(a is b)           # อาจได้ False! เพราะเป็นคนละก้อนในหน่วยความจำ
กฎง่าย ๆ: ใช้ is เฉพาะกับ None, True, False เท่านั้น · เทียบค่าอื่นทั้งหมดใช้ ==

โค้ดนี้พิมพ์บรรทัดสุดท้ายว่าอะไร?

loop จบเมื่อ n เป็น 0 (เพราะ 0 > 0 เป็นเท็จ) ค่าที่เหลืออยู่ในตัวแปรจึงเป็น 0

    print('Lather')
    print('Rinse')

n = 0 แล้ว while n > 0 : — โค้ดข้างใน loop ทำงานกี่รอบ?
while เช็กเงื่อนไขก่อนเข้ารอบแรกเสมอ — 0 > 0 เป็นเท็จ จึงข้ามทั้ง loop ไปเลย
ถ้าย้าย total = 0 เข้าไปไว้ใน loop จะเกิดอะไรขึ้น?
ตัวแปรสะสมต้องตั้งค่าครั้งเดียวก่อนเข้า loop เท่านั้น
largest = -1 แล้ววนหาค่ามากสุดใน [-5, -3, -9] จะได้อะไร?
ไม่มีตัวไหนมากกว่า -1 เลย ค่าเริ่มต้นจึงไม่ถูกแทนที่ — ต้องเริ่มด้วย None แทน
ทำไมโค้ดหาค่าน้อยสุดถึงเขียน if smallest is None ไว้เป็นเงื่อนไขแรก?
รอบแรก smallest ยังไม่มีค่า จึงเอาตัวแรกในข้อมูลมาใช้เลย ทำให้ใช้ได้กับข้อมูลทุกช่วงค่า
ควรใช้ is แทน == เมื่อไร?
is ถามว่า "เป็นวัตถุตัวเดียวกันไหม" ไม่ใช่ "ค่าเท่ากันไหม" — กับตัวเลขหรือข้อความอาจให้ผลไม่ตรงที่คิด

for รู้จำนวนรอบแน่นอน (definite) ส่วน while วนจนกว่าเงื่อนไขจะเป็นเท็จ ไม่รู้ล่วงหน้า (indefinite)

print("*** Minimum value ***")

ip = input("Enter some numbers: ").split()

smallest = None
for s in ip:
    number = float(s)
    if smallest is None:
        smallest = number
    elif number < smallest:
        smallest = number

if smallest is None:
    print("No input")

โจทย์ 5 — ท้าทาย: Shift Cipher

รับข้อความและตัวเลข 1-26 ในบรรทัดเดียว แล้วถอดรหัสโดยเลื่อนตัวอักษรลง ตามเลขที่รับมา แสดงผลเป็นตัวพิมพ์ใหญ่ทั้งหมด

  • dEF 3 → ABC  (d ถอย 3 ตัวได้ a)
  • ifMMp 1 → HELLO
  • ถอยเลย A แล้วให้วนกลับไปที่ Z — เช่น a 3 → X
  • ถ้าเลขไม่อยู่ในช่วง 1-26 ให้แสดง Number must be between 1-26

ใบ้: ord('A') ได้ 65 · chr(65) ได้ 'A' · ใช้ % 26 จัดการการวนกลับ

Enter a word and a number: WHVWFLSKHU 3
TESTCIPHER

Enter a word and a number: testcipher 0
Number must be between 1-26
▸ ดูเฉลย 
data = input("Enter a word and a number: ").split()
word = data[0]
key = int(data[1])

if key < 1 or key > 26:
    print("Number must be between 1-26")
else:
    result = ""
    for ch in word.upper():
        # A=0, B=1, ... Z=25 แล้วถอยตาม key
        pos = ord(ch) - ord('A')
        new_pos = (pos - key) % 26      # % 26 ทำให้วนกลับเองเมื่อติดลบ
        result = result + chr(new_pos + ord('A'))
    print(result)

# ไล่ตรวจ 'a' กับ key 3:
#   pos = 0 ; (0 - 3) % 26 = 23 ; chr(23 + 65) = 'X'  ✓

วาด flowchart ที่ใช้ทั้ง Counting และ Summing ใน loop เดียว เพื่อหาค่าเฉลี่ยของ nums แล้วเขียนโค้ดตาม

▸ ดูเฉลย 
count = 0
total = 0
for x in nums:
    count += 1
    total += x
avg = total / count
print(count, avg)
