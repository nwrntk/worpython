Computer Programming · Lab

Python พื้นฐาน
List · Tuple · Iteration

บทเรียนสั้น ๆ พร้อมแบบทดสอบท้ายบท อ่านจบแล้วต้องเขียนโค้ดได้จริง

ทั้ง 4 บทนี้เรียงต่อกัน อ่านตามลำดับจะได้ผลดีที่สุด แต่ละบทมี แบบทดสอบแบบเลือกตอบ ให้เช็กความเข้าใจ และ โจทย์ให้ไปเขียนโค้ดจริง พร้อมเฉลยที่กดเปิดดูได้เมื่อทำเสร็จแล้ว

CHAPTER 01
List — ลิสต์
เก็บข้อมูลหลายค่าในตัวแปรเดียว เข้าถึงด้วย index, ตัดด้วย slice, แก้ไขได้
CHAPTER 02
Tuple — ทูเพิล
เหมือน list แต่แก้ไม่ได้ ใช้เมื่อข้อมูลต้องคงที่ และการ unpack ค่า
CHAPTER 03
for loop
วนซ้ำเมื่อรู้จำนวนรอบ — range, enumerate, zip, loop ซ้อน loop
CHAPTER 04
while loop
วนซ้ำเมื่อไม่รู้จำนวนรอบ — เงื่อนไข, break, continue, infinite loop

วิธีใช้หน้าเว็บนี้

  • กด S เพื่อซ่อน/แสดงเมนูด้านซ้าย
  • กด ← → เพื่อข้ามไปบทก่อนหน้า/บทถัดไป
  • แบบทดสอบเลือกตอบได้ ครั้งเดียวต่อข้อ — คิดให้ดีก่อนกด
  • โจทย์เขียนโค้ด ให้เปิดไฟล์ .py ลองพิมพ์เองก่อน แล้วค่อยกดดูเฉลย
ก่อนเริ่ม: เปิดโปรแกรม Python ไว้ข้าง ๆ ด้วย ทุกโค้ดในบทเรียนนี้ ควรลองพิมพ์รันเองอย่างน้อยหนึ่งรอบ — อ่านอย่างเดียวจะจำไม่ได้
