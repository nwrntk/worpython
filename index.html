Python พื้นฐาน
ตั้งแต่ print ถึงการเขียนไฟล์

บทเรียนสั้น ๆ พร้อมแบบทดสอบท้ายบท อ่านจบแล้วต้องเขียนโค้ดได้จริง

ทั้ง 13 บทนี้เรียงต่อกันจากง่ายไปยาก อ่านตามลำดับจะได้ผลดีที่สุด เพราะบทหลัง ๆ ใช้ของจากบทก่อนหน้าตลอด แต่ละบทมี แบบทดสอบแบบเลือกตอบ ให้เช็กความเข้าใจ และ โจทย์ให้ไปเขียนโค้ดจริง พร้อมเฉลยที่กดเปิดดูได้เมื่อทำเสร็จแล้ว

I · พื้นฐาน

CHAPTER 01
print และตัวแปร
แสดงผลด้วย print, เก็บค่าในตัวแปร, รับค่าด้วย input, f-string, คอมเมนต์
CHAPTER 02
ชนิดข้อมูลและตัวดำเนินการ
int / float / str / bool, แปลงชนิด, // % **, เปรียบเทียบ, and / or / not

II · การตัดสินใจ

CHAPTER 03
เงื่อนไข if / elif / else
ให้โปรแกรมเลือกทางเอง — ลำดับเงื่อนไข, if ซ้อน, เงื่อนไขซับซ้อน

III · ข้อมูลชุด

CHAPTER 04
List — ลิสต์
เก็บข้อมูลหลายค่าในตัวแปรเดียว เข้าถึงด้วย index, ตัดด้วย slice, แก้ไขได้
CHAPTER 05
Tuple — ทูเพิล
เหมือน list แต่แก้ไม่ได้ ใช้เมื่อข้อมูลต้องคงที่ และการ unpack ค่า

IV · การวนซ้ำ

CHAPTER 06
for loop
วนซ้ำเมื่อรู้จำนวนรอบ — range, enumerate, zip, loop ซ้อน loop
CHAPTER 07
while loop
วนซ้ำเมื่อไม่รู้จำนวนรอบ — เงื่อนไข, break, continue, infinite loop
CHAPTER 08
Loop Patterns
7 รูปแบบที่ใช้ซ้ำทุกโปรแกรม — นับ, รวม, เฉลี่ย, กรอง, ค้นหา, มากสุด, น้อยสุด

V · ข้อมูลแบบกลุ่ม

CHAPTER 09
Dictionary — ดิกชันนารี
เก็บข้อมูลเป็นคู่ key → value ค้นด้วยชื่อ, .get(), .items(), นับของ
CHAPTER 10
Set — เซต
กลุ่มข้อมูลที่ห้ามซ้ำ — ตัดค่าซ้ำ, หาส่วนร่วม, union / intersection

VI · ข้อความและฟังก์ชัน

CHAPTER 11
String — ข้อความ
slice, split / join, replace, f-string จัดรูปแบบตัวเลขและตาราง
CHAPTER 12
Function — ฟังก์ชัน
def, พารามิเตอร์, ค่า default, return กับ print, ขอบเขตตัวแปร

VII · ไฟล์และข้อผิดพลาด

CHAPTER 13
File I/O & Exception
อ่าน-เขียนไฟล์ด้วย with open, try-except กันโปรแกรมพัง

VIII · Lib สำคัญ

CHAPTER 14

อ่าน-แสดง-บันทึกรูป, ภาพคือ array, แปลงสี, วาดทับ, กล้อง และตรวจจับใบหน้า
CHAPTER 15

CHAPTER 16
