Chapter 02

ชนิดข้อมูลและตัวดำเนินการ

ข้อมูลแต่ละชนิดทำอะไรได้ไม่เหมือนกัน — รู้ชนิดแล้วจะเข้าใจว่าทำไมโค้ดถึงพัง

2.1 ชนิดข้อมูลพื้นฐาน 4 แบบ

ชนิดชื่อเต็มตัวอย่างใช้เก็บ
intinteger20, -5, 0จำนวนเต็ม
floatfloating point3.45, -0.5, 2.0ทศนิยม
strstring"ฟ้าใส", "20"ข้อความ
boolbooleanTrue, Falseจริง / เท็จ
age    = 20          # int
gpa    = 3.45        # float
name   = "ฟ้าใส"      # str
passed = True        # bool ← T ตัวใหญ่ ไม่ใช่ true

print(type(age))     # <class 'int'>
print(type(gpa))     # <class 'float'>
print(type(name))    # <class 'str'>
print(type(passed))  # <class 'bool'>
20 กับ "20" คนละชนิดกัน
20 + 1 ได้ 21 · "20" + "1" ได้ "201" (ต่อข้อความ) · "20" + 1 ได้ TypeError

2.2 แปลงชนิดข้อมูล (Type Casting)

s = "42"

n = int(s)          # "42" → 42     (str เป็น int)
f = float(s)        # "42" → 42.0   (str เป็น float)
t = str(42)         # 42   → "42"   (int เป็น str)

print(int(3.9))     # 3   ← ตัดทิ้ง ไม่ปัดเศษ!
print(round(3.9))   # 4   ← ถ้าจะปัดเศษต้องใช้ round()
print(float(5))     # 5.0

แปลงไม่ได้จะเกิด error

int("สวัสดี")     # ValueError: invalid literal for int()
int("3.5")        # ValueError ← int() รับได้เฉพาะเลขจำนวนเต็มล้วน
int(float("3.5")) # 3 ← ต้องแปลงผ่าน float ก่อน

2.3 ตัวดำเนินการทางคณิตศาสตร์

เครื่องหมายความหมายตัวอย่างผลลัพธ์
+บวก7 + 29
-ลบ7 - 25
*คูณ7 * 214
/หาร (ได้ float เสมอ)7 / 23.5
//หารปัดลง (เอาส่วน)7 // 23
%หารเอาเศษ (modulo)7 % 21
**ยกกำลัง7 ** 249
% ใช้บ่อยกว่าที่คิด:
n % 2 == 0 → เช็กเลขคู่ · n % 10 → เอาหลักสุดท้าย · i % 3 == 0 → ทำทุก 3 รอบ 
print(10 / 3)      # 3.3333333333333335
print(10 // 3)     # 3
print(10 % 3)      # 1
print(2 ** 10)     # 1024
print(-7 // 2)     # -4  ← ปัดลง ไม่ใช่ตัดทิ้ง

ลำดับการคำนวณเหมือนคณิตศาสตร์ — วงเล็บ → ยกกำลัง → คูณหาร → บวกลบ

print(2 + 3 * 4)      # 14  ไม่ใช่ 20
print((2 + 3) * 4)    # 20  ← ใส่วงเล็บถ้าอยากคุมลำดับ

เขียนย่อเมื่ออัปเดตค่าตัวเดิม

x = 10
x += 5      # เหมือน x = x + 5  → 15
x -= 3      # 12
x *= 2      # 24
x /= 4      # 6.0

2.4 ตัวดำเนินการเปรียบเทียบ

ผลลัพธ์เป็น bool เสมอ — จะได้เอาไปใช้ต่อในเงื่อนไข (บทที่ 3)

เครื่องหมายความหมายตัวอย่างผล
==เท่ากับ5 == 5True
!=ไม่เท่ากับ5 != 3True
>มากกว่า5 > 3True
<น้อยกว่า5 < 3False
>=มากกว่าหรือเท่ากับ5 >= 5True
<=น้อยกว่าหรือเท่ากับ3 <= 5True
= กับ == ต่างกันมาก
x = 5 คือ กำหนดค่า ให้ x เป็น 5
x == 5 คือ ถาม ว่า x เท่ากับ 5 ไหม (ได้ True/False)
เขียนสลับกันเป็นความผิดพลาดที่พบบ่อยที่สุดของคนเริ่มเรียน 
score = 85

print(score >= 50)      # True
print(score == 100)     # False
print("a" < "b")        # True ← string เทียบตามลำดับตัวอักษร
print(3 < score < 90)   # True ← เขียนต่อกันได้เลย

2.5 ตัวดำเนินการตรรกะ

คำสั่งเป็นจริงเมื่อตัวอย่าง
andจริงทั้งสองข้างage >= 18 and has_id
orจริงอย่างน้อยหนึ่งข้างis_vip or points > 100
notกลับผลลัพธ์not is_banned
age = 20
has_id = True

print(age >= 18 and has_id)     # True  ← จริงทั้งคู่
print(age >= 60 or has_id)      # True  ← ข้างขวาจริงก็พอ
print(not has_id)               # False

# รวมกันได้ ใส่วงเล็บให้อ่านง่าย
score = 85
attendance = 0.9
print((score >= 50) and (attendance >= 0.8))    # True

2.6 ค่าที่ถือว่าเป็นเท็จ

Python มองค่าเหล่านี้เป็น False ทั้งหมด นอกนั้นเป็น True

print(bool(0))        # False
print(bool(0.0))      # False
print(bool(""))       # False ← string ว่าง
print(bool([]))       # False ← list ว่าง
print(bool(None))     # False

print(bool(1))        # True
print(bool(-5))       # True ← ติดลบก็ True
print(bool("0"))      # True ← มีตัวอักษรอยู่จริง
print(bool(" "))      # True ← ช่องว่างก็นับ
bool คือ int ชนิดพิเศษ: True มีค่าเท่ากับ 1 และ False เท่ากับ 0
True + True ได้ 2 · sum([True, False, True]) ได้ 2 (เอาไว้นับจำนวนเงื่อนไขที่เป็นจริงได้)

2.7 Flowchart — แปลงชนิดก่อนคำนวณ

ข้อมูลจาก input() เป็น str เสมอ ใน flowchart ให้วาดการแปลงชนิด เป็นกล่อง process แยกออกมา จะได้ไม่ลืมเวลาเขียนโค้ด

text = input("องศา F: ")
f = float(text)
c = (f - 32) * 5 / 9
print(f"{c:.1f} °C")

เลือกได้ข้อละครั้งเดียว คิดก่อนกด

print(10 / 2) ได้อะไร?
/ คืน float เสมอแม้หารลงตัว ถ้าอยากได้ int ต้องใช้ //
"20" + 1 เกิดอะไรขึ้น?

17 % 5 ได้อะไร?
17 หาร 5 ได้ 3 เหลือเศษ 2 — % คือเศษ ส่วน // คือส่วน (3)
x = 5 ต่างจาก x == 5 ยังไง?
สลับสองอันนี้เป็นข้อผิดพลาดยอดฮิต — ในเงื่อนไข if ต้องใช้ == เท่านั้น
bool("") และ bool("0") ได้อะไรตามลำดับ?
string ว่างเป็นเท็จ แต่ "0" มีตัวอักษรอยู่ 1 ตัวจึงเป็นจริง
2 + 3 * 4 ได้อะไร?
คูณก่อนบวก → 3*4=12 แล้ว +2 = 14 (ถ้าอยากได้ 20 ต้องใส่วงเล็บ)
ตาม flowchart นี้ ถ้าผู้ใช้พิมพ์ 5 จะแสดงอะไร?
text เป็น str การคูณ str ด้วย 2 คือต่อข้อความซ้ำ → "55" · flowchart นี้ขาดกล่อง int(text) ก่อนคำนวณ

โจทย์ 1 — สำรวจชนิดข้อมูล

สร้างตัวแปร 5 ตัวที่มีชนิดต่างกัน (int, float, str, bool และผลลัพธ์ของการเปรียบเทียบ) แล้วพิมพ์ทั้งค่าและชนิดของแต่ละตัวด้วย type()

▸ ดูเฉลย 
a = 20
b = 3.45
c = "ฟ้าใส"
d = True
e = (10 > 5)

print(a, type(a))
print(b, type(b))
print(c, type(c))
print(d, type(d))
print(e, type(e))     # True <class 'bool'>

โจทย์ 2 — แยกหลักของตัวเลข

รับเลข 3 หลักจากผู้ใช้ แล้วแยกพิมพ์หลักร้อย หลักสิบ หลักหน่วย และบอกผลรวมของทั้งสามหลัก (ใช้ // กับ %)

▸ ดูเฉลย 
n = int(input("เลข 3 หลัก: "))

h = n // 100          # หลักร้อย
t = (n // 10) % 10    # หลักสิบ
u = n % 10            # หลักหน่วย

print(f"หลักร้อย: {h}")
print(f"หลักสิบ: {t}")
print(f"หลักหน่วย: {u}")
print(f"ผลรวม: {h + t + u}")

โจทย์ 3 — แปลงหน่วยเวลา

รับจำนวนวินาทีทั้งหมด แล้วแปลงเป็นรูปแบบ ชั่วโมง:นาที:วินาที เช่น 3725 วินาที → 1:2:5 (ใช้ // และ %)

▸ ดูเฉลย 
total = int(input("จำนวนวินาที: "))

h = total // 3600
m = (total % 3600) // 60
s = total % 60

print(f"{h}:{m}:{s}")
print(f"{h:02d}:{m:02d}:{s:02d}")    # เติม 0 ข้างหน้า → 01:02:05

โจทย์ 4 — ท้าทาย: ตรวจเงื่อนไขด้วย bool

รับคะแนนสอบ (0-100) และเปอร์เซ็นต์การเข้าเรียน (0-100) จากผู้ใช้ แล้วพิมพ์ผลของเงื่อนไขเหล่านี้เป็น True/False โดยยังไม่ต้องใช้ if:

  • คะแนนผ่าน (≥ 50)
  • เข้าเรียนพอ (≥ 80)
  • ผ่านทั้งสองเกณฑ์
  • ตกเกณฑ์อย่างน้อยหนึ่งข้อ
  • ได้เกียรตินิยม (คะแนน ≥ 80 และเข้าเรียน 100)
▸ ดูเฉลย 
score = float(input("คะแนนสอบ: "))
att = float(input("เข้าเรียน (%): "))

pass_score = score >= 50
pass_att = att >= 80

print("คะแนนผ่าน:", pass_score)
print("เข้าเรียนพอ:", pass_att)
print("ผ่านทั้งสอง:", pass_score and pass_att)
print("ตกอย่างน้อยหนึ่งข้อ:", not (pass_score and pass_att))
print("เกียรตินิยม:", score >= 80 and att == 100)

# นับว่าผ่านกี่เกณฑ์ — ใช้ได้เพราะ True มีค่า 1
print("ผ่าน", pass_score + pass_att, "เกณฑ์จาก 2")

โจทย์ 5 — วาด Flowchart

รับจำนวนนาทีทั้งหมด (เช่น 135) แล้วแสดงเป็นชั่วโมงกับนาที (2 ชั่วโมง 15 นาที) วาด flowchart ก่อน แล้วค่อยเขียนโค้ด (ใบ้: // กับ %)

▸ ดูเฉลย 
total = int(input("จำนวนนาที: "))
h = total // 60
m = total % 60
print(f"{h} ชั่วโมง {m} นาที")

โจทย์ 6 — แก้บั๊กด้วยการอ่าน error

โค้ดนี้มีบั๊ก 3 จุด ให้รันแล้วอ่าน error ทีละตัว แก้ทีละจุดแล้วรันใหม่ จนได้ สวัสดี ฟ้า กับ ปีหน้าอายุ 21 (พิมพ์ชื่อ ฟ้า อายุ 20)

name = input("ชื่อ: ")
age = input("อายุ: ")
print("สวัสดี " + nmae)
print("ปีหน้าอายุ " + age + 1)
▸ ดูเฉลย 
# รอบ 1: NameError: name 'nmae' is not defined
#        → สะกดผิด แก้เป็น name
# รอบ 2: TypeError: can only concatenate str (not "int") to str
#        → age เป็น str เอาไป + 1 ไม่ได้ ครอบ int()
# รอบ 3: TypeError: can only concatenate str (not "int") to str  ← ข้อความเดิม!
#        → คราวนี้ age เป็น int แล้ว แต่เอา int ไปต่อกับข้อความ ใช้ f-string
name = input("ชื่อ: ")
age = int(input("อายุ: "))
print("สวัสดี " + name)
print(f"ปีหน้าอายุ {age + 1}")

รอบ 2 กับ 3 ข้อความ error เหมือนกันเป๊ะ แต่สาเหตุต่างกัน · ดู ^ ว่าชี้ตรงไหนทุกครั้ง อย่าเดาจากข้อความอย่างเดียว
