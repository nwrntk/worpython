เงื่อนไข — if / elif / else

ให้โปรแกรมตัดสินใจเองว่าจะทำอะไร ตามข้อมูลที่ได้รับ

3.1 if — ทำเมื่อจริง

score = 85

if score >= 50:
    print("สอบผ่าน")

# สอบผ่าน

ถ้าเงื่อนไขเป็น True โค้ดที่เยื้องเข้าไปจะทำงาน ถ้าเป็น False ก็ข้ามไปเลย

score = 30

if score >= 50:
    print("สอบผ่าน")      # ← ไม่ทำงาน

print("จบการตรวจ")        # ← ทำเสมอ เพราะอยู่นอก if
2 อย่างที่ลืมบ่อยที่สุด
1. เครื่องหมาย : ท้ายบรรทัด if
2. การเยื้อง (indent) 4 ช่อง — Python ใช้การเยื้องบอกว่าโค้ดไหนอยู่ใน if ไม่ได้ใช้ปีกกาเหมือนภาษาอื่น

3.2 if-else — ทำอย่างใดอย่างหนึ่ง

score = 30

    print("สอบผ่าน")
else:
    print("สอบตก")

# สอบตก

else ไม่มีเงื่อนไข เพราะมันคือ "กรณีอื่นทั้งหมด" — มีทางเดียวเท่านั้นที่จะถูกเลือก

age = int(input("อายุ: "))

if age >= 18:
    print("เข้าชมได้")
else:
    print("อายุไม่ถึง")

3.3 if-elif-else — หลายทางเลือก

score = 75

if score >= 80:
    grade = "A"
elif score >= 70:
    grade = "B"
elif score >= 60:
    grade = "C"
elif score >= 50:
    grade = "D"
else:
    grade = "F"

print("เกรด", grade)      # เกรด B
Python ตรวจจากบนลงล่าง แล้วหยุดที่ข้อแรกที่เป็นจริง
ตัวอย่างข้างบน คะแนน 75 ผ่านทั้ง >= 70, >= 60 และ >= 50 แต่ได้ B เพราะเจอเงื่อนไขนั้นก่อน ที่เหลือไม่ถูกตรวจเลย

เพราะเหตุนี้ ลำดับจึงสำคัญมาก — เขียนสลับแล้วผลจะผิด

# ผิด! ทุกคนที่ได้ 50 ขึ้นไปจะได้ D หมด
if score >= 50:
    grade = "D"
elif score >= 80:      # ไม่มีวันถูกตรวจถึง
    grade = "A"

3.8 Flowchart ของ if — 4 แบบ

เงื่อนไขทุกตัววาดเป็นสี่เหลี่ยมข้าวหลามตัด มีลูกศรเข้า 1 เส้น ออก 2 เส้นเสมอ คือ จริง กับ เท็จ แล้วทุกทางต้องมาบรรจบกันก่อนทำงานต่อ ต่อเพชรหลายอันเข้าด้วยกันได้ 4 แบบ ซึ่งทำงานต่างกัน

แบบที่ 1 · if if if — ถามทุกข้อ

เหมาะกับเงื่อนไขที่เป็นอิสระต่อกัน จริงพร้อมกันหลายข้อได้ ทางเท็จไม่มีกล่อง แค่ลากเส้นลงไปถามข้อถัดไปเลย

โจทย์ 1 — เลขคู่หรือคี่

รับตัวเลขจากผู้ใช้ แล้วบอกว่าเป็นเลขคู่หรือคี่ และเป็นบวก ลบ หรือศูนย์

โจทย์ 4 — ตรวจสามเหลี่ยม

รับความยาวด้าน 3 ด้าน แล้วบอกว่า:

  1. ประกอบเป็นสามเหลี่ยมได้ไหม (ผลรวมสองด้านใด ๆ ต้องมากกว่าด้านที่สาม)
  2. ถ้าได้ เป็นสามเหลี่ยมด้านเท่า หน้าจั่ว หรือด้านไม่เท่า
▸ ดูเฉลย 
a = float(input("ด้านที่ 1: "))
b = float(input("ด้านที่ 2: "))
c = float(input("ด้านที่ 3: "))

if a <= 0 or b <= 0 or c <= 0:
    print("ความยาวด้านต้องมากกว่า 0")
elif a + b <= c or a + c <= b or b + c <= a:
    print("ประกอบเป็นสามเหลี่ยมไม่ได้")
else:
    if a == b == c:
        print("สามเหลี่ยมด้านเท่า")
    elif a == b or b == c or a == c:
        print("สามเหลี่ยมหน้าจั่ว")
    else:
        print("สามเหลี่ยมด้านไม่เท่า")

โจทย์ 5 — ท้าทาย: เครื่องคิดเลข

รับตัวเลข 2 ตัวและเครื่องหมาย (+ - * / %) แล้วคำนวณตามเครื่องหมายนั้น พร้อมดัก 2 กรณี: เครื่องหมายที่ไม่รู้จัก และการหารด้วยศูนย์

▸ ดูเฉลย 
a = float(input("ตัวที่ 1: "))
op = input("เครื่องหมาย (+ - * / %): ").strip()
b = float(input("ตัวที่ 2: "))

if op == "+":
    print(f"{a} + {b} = {a + b}")
elif op == "-":
    print(f"{a} - {b} = {a - b}")
elif op == "*":
    print(f"{a} * {b} = {a * b}")
elif op == "/" or op == "%":
    if b == 0:
        print("หารด้วยศูนย์ไม่ได้")
    elif op == "/":
        print(f"{a} / {b} = {a / b}")
    else:
        print(f"{a} % {b} = {a % b}")
else:
    print(f"ไม่รู้จักเครื่องหมาย '{op}'")
ต่อไป: ตอนนี้โปรแกรมตัดสินใจได้แล้ว บทถัดไปจะเก็บข้อมูลหลายค่าไว้ในตัวแปรเดียวด้วย list แล้วค่อยเอามาวนซ้ำในบทที่ 6-7
