14.1 ทำไมต้องมี NumPy

ถ้าข้อมูลมีเป็นพัน ๆ ตัว การใช้ list กับ for จะเขียนยาวและช้า · NumPy เก็บตัวเลขเป็น array แล้วสั่งคำนวณทั้งชุดในบรรทัดเดียว

scores = [80, 75, 92, 68]

# แบบ list ต้องวนทีละตัว
plus = []
for s in scores:
    plus.append(s + 5)
print(plus)                  # [85, 80, 97, 73]
import numpy as np

scores = np.array([80, 75, 92, 68])

# แบบ array บวกทั้งชุดในบรรทัดเดียว
print(scores + 5)                      # [85 80 97 73]
print(scores.mean())                   # 78.75
print(scores.max())                    # 92

14.3 คำนวณทั้งชุดทีเดียว

เครื่องหมายคำนวณทุกตัวทำกับทุกช่องพร้อมกัน เรียกว่า vectorize · ไม่ต้องเขียน loop เลย

import numpy as np

a = np.array([10, 20, 30])
b = np.array([1, 2, 3])

print(a + b)                  # [11 22 33]
print(a * 2)                  # [20 40 60]
print(a / b)                  # [10. 10. 10.]
print(a ** 2)                 # [100 400 900]
print(a - b)                  # [ 9 18 27]

ใช้กับสูตรจริงได้ทันที เช่น แปลงองศาเซลเซียสเป็นฟาเรนไฮต์ทั้งชุด

14.5 เลือกด้วยเงื่อนไข

เอาเงื่อนไขใส่ใน [ ] ได้เลย เรียกว่า boolean mask — ใช้บ่อยที่สุดในงานข้อมูลจริง

import numpy as np

scores = np.array([80, 45, 92, 50, 68])

print(scores >= 50)
print(scores[scores >= 50])
print((scores >= 50).sum())
print(scores[(scores >= 50) & (scores < 90)])
[ True False  True  True  True]
[80 92 50 68]
4
[80 50 68]
ต้องใช้ & | ไม่ใช่ and or และต้องใส่วงเล็บครอบแต่ละเงื่อนไข · เพราะ and ถามว่า "ทั้งก้อนจริงไหม" แต่เราต้องการเทียบทีละช่อง 
import numpy as np

scores = np.array([80, 45, 92])
print(scores[(scores > 50) and (scores < 90)])
ValueError: The truth value of an array with more than one element is ambiguous. Use a.any() or a.all()

np.where ใช้แทนค่าแบบมีเงื่อนไข เหมือน if-else ที่ทำทั้งชุด

import numpy as np

scores = np.array([80, 45, 92, 50])
print(np.where(scores >= 50, "ผ่าน", "ไม่ผ่าน"))
print(np.where(scores < 50, 0, scores))
['ผ่าน' 'ไม่ผ่าน' 'ผ่าน' 'ผ่าน']
[80  0 92 50]

14.6 สรุปค่าทางสถิติ

import numpy as np

s = np.array([80, 75, 92, 68, 88])

print(s.sum())                        # 403

a = np.array([1, 2, 3]) แล้ว a * 2 ได้อะไร?
array คูณเลขคือคูณทุกช่อง · ต่างจาก list ที่ [1, 2, 3] * 2 จะได้ list ยาวขึ้นเป็นสองเท่า

แบบทดสอบ · เลือกตอบ

np.arange(0, 10, 2) ได้อะไร?
เหมือน range() คือไม่รวมเลขท้าย · ต่างกันตรงที่ arange คืน array และรับทศนิยมได้
scores[scores >= 50] คืออะไร?
ข้างในวงเล็บคือ array ของ True/False · NumPy หยิบเฉพาะช่องที่เป็น True
ทำไมเขียน a[(a > 1) and (a < 5)] ไม่ได้?
array หลายช่องตอบจริง/เท็จเป็นค่าเดียวไม่ได้ Python จึงโยน ValueError · ใช้ & | พร้อมวงเล็บครอบ
v = a[0:2] แล้วแก้ v[0] = 99 · a เปลี่ยนไหม?
ต่างจาก list ในบทที่ 4 ที่ a[:] ได้สำเนา · ถ้าต้องการสำเนาใน NumPy ต้อง .copy()
np.array([1, 2, "สาม"]).dtype เป็นอะไร?
array เก็บชนิดเดียวทั้งก้อน จึงยกระดับให้เป็นชนิดที่เก็บได้ทุกตัว คือ string · คำนวณต่อไม่ได้
อยากให้ผลสุ่มออกมาเหมือนเดิมทุกครั้งที่รัน ต้องทำอะไร?
seed เดียวกันให้ลำดับตัวเลขเดิมเสมอ · จำเป็นเวลาต้องให้คนอื่นทำผลการทดลองซ้ำได้

โจทย์ 1 — สรุปคะแนนทั้งห้อง

มีคะแนน [55, 90, 42, 78, 88, 61] ให้ใช้ NumPy หา จำนวนคนที่ได้ 60 ขึ้นไป, ค่าเฉลี่ยเฉพาะคนที่ผ่าน, และคะแนนสูงสุด

▸ ดูเฉลย 
import numpy as np

s = np.array([55, 90, 42, 78, 88, 61])
passed = s[s >= 60]

print(len(passed))                        # 4
print(passed.mean().round(2))             # 79.25
print(s.max())                            # 90

โจทย์ 2 — ข้อมูลเซนเซอร์ 3 วัน

ตารางความชื้น 3 วัน วันละ 4 ครั้ง ให้หาค่าเฉลี่ยของแต่ละวัน, วันที่ค่าเฉลี่ยสูงสุด (เป็นเลขแถว) และแทนค่าที่ต่ำกว่า 50 ด้วย 50
