0.1 ต้องมีอะไรบ้าง

สิ่งที่ต้องมีทำหน้าที่เทียบง่าย ๆ

ต้องมีทั้งสองอย่าง · editor อย่างเดียวรันโค้ดไม่ได้ ต้องมี Python ในเครื่องด้วย

Pythonpython.org/downloads VS Codecode.visualstudio.com Thonnythonny.org

0.2 ติดตั้ง Python

  1. เข้า python.org/downloads แล้วกดปุ่มดาวน์โหลดเวอร์ชันล่าสุด (ใช้ 3.12 ขึ้นไป · ตัวอย่างในเว็บนี้รันด้วย 3.13)
  2. เปิดไฟล์ที่โหลดมา
  3. Windows: ติ๊กช่อง Add python.exe to PATH ที่ด้านล่างของหน้าต่างแรก แล้วกด Install Now
  4. macOS: กดถัดไปจนจบได้เลย
อย่าลืมติ๊ก Add python.exe to PATH เป็นสาเหตุอันดับหนึ่งที่รันไม่ได้ ถ้าลืมไปแล้ว ให้เปิดตัวติดตั้งอีกรอบ เลือก Modify หรือถอนแล้วติดตั้งใหม่ · หน้าตาตัวติดตั้งอาจเปลี่ยนไปตามเวอร์ชัน ถ้าไม่เห็นช่องนี้ ให้ทำตามขั้นตอนบนหน้าดาวน์โหลด แล้วใช้ขั้นเช็กข้างล่างยืนยันว่าพร้อมใช้

เช็กว่าติดตั้งสำเร็จ เปิด Terminal (Windows: ค้นหา Command Prompt หรือ PowerShell · macOS: Terminal) แล้วพิมพ์

python --version
# Python 3.13.7   ← ได้ประมาณนี้ = พร้อมใช้

บน macOS ให้พิมพ์ python3 แทน python ทุกครั้งที่เจอในเว็บนี้

0.3 เลือกโปรแกรมเขียนโค้ด

โปรแกรมจุดเด่นเหมาะกับ
VS Code (แนะนำ)ฟรี ใช้กันทั่วโลก มีตัวช่วยเติมโค้ดและเตือนที่ผิด ใช้ต่อได้ยาว ๆ ถึงบทที่ 14–16
Thonnyหน้าตาเรียบ มี Python มาในตัว กดรันแล้วดูค่าตัวแปรทีละบรรทัดได้ อยากเริ่มเร็วที่สุด ไม่อยากตั้งค่าอะไร

0.4 ตั้งค่า VS Code และ extension

VS Code ที่เพิ่งลงยังไม่รู้จัก Python · extension คือโปรแกรมเสริมที่เพิ่มความสามารถให้ VS Code เหมือนแอปในมือถือ ติดตั้งเพิ่มได้ทีละตัว

ติดตั้ง extension

  1. กดไอคอน Extensions แถบซ้าย (รูปสี่เหลี่ยม 4 ช่อง) หรือ Ctrl+Shift+X (macOS ⌘+Shift+X)
  2. พิมพ์ชื่อ extension ในช่องค้นหา
  3. ดูชื่อผู้พัฒนาใต้ชื่อ extension ให้ตรง แล้วกด Install
ค้นคำว่า Python จะเจอหลายตัวชื่อคล้ายกัน ตัวที่ถูกคือผู้พัฒนา Microsoft ที่มีเครื่องหมายยืนยัน ✓ และยอดติดตั้งสูงสุด · ติดตั้งเฉพาะตัวที่รู้ว่าทำอะไร extension ทุกตัวเข้าถึงไฟล์ในเครื่องได้

เลือก Python ที่ VS Code จะใช้

มุมขวาล่างของ VS Code (ตอนเปิดไฟล์ .py) จะบอกเวอร์ชัน Python ที่ใช้อยู่ เช่น 3.13.7 ถ้าไม่ขึ้น หรือขึ้นไม่ตรงกับที่ติดตั้ง

  1. กด Ctrl+Shift+P (macOS ⌘+Shift+P)
  2. พิมพ์ Python: Select Interpreter แล้วกด Enter
  3. เลือกตัวที่เลขเวอร์ชันตรงกับที่ติดตั้งจาก python.org

สำคัญมากตอนบทที่ 14 · ถ้าเครื่องมี Python หลายตัว pip install อาจไปลงคนละตัวกับที่ VS Code ใช้ แล้วได้ ModuleNotFoundError ทั้งที่ติดตั้งแล้ว

ตั้งค่าที่ช่วยให้เรียนง่ายขึ้น

ตั้งค่าวิธีทำไม
บันทึกอัตโนมัติเมนู File → Auto Saveไม่เจอปัญหา "แก้แล้วแต่รันได้ผลเดิม"
ขยาย / ย่อตัวอักษรCtrl+= / Ctrl+-อ่านง่ายขึ้น เวลาฉายจอหน้าห้อง
เปิด / ปิด TerminalCtrl+`ใช้พิมพ์ python และ pip
เส้นหยักสีแดงใต้โค้ด คือ VS Code เจอที่ผิดก่อนจะรัน เอาเมาส์ชี้จะเห็นข้อความ (หรือเห็นท้ายบรรทัดเลยถ้าลง Error Lens) อ่านแบบเดียวกับ error ตอนรัน ดู คู่มืออ่าน error

0.5 เขียนและรันไฟล์แรก

  1. สร้างโฟลเดอร์สำหรับเก็บงาน เช่น python-lab ไว้ที่ Desktop
  2. VS Code: File → Open Folder เลือกโฟลเดอร์นั้น
  3. สร้างไฟล์ใหม่ชื่อ hello.py · ต้องลงท้ายด้วย .py
  4. พิมพ์โค้ดข้างล่าง แล้วบันทึก (Ctrl+S · macOS ⌘+S)
  5. กดปุ่ม ▶ มุมขวาบน (Run Python File)
print("สวัสดี Python")
print(2 + 3)

ผลจะขึ้นที่แถบ Terminal ด้านล่าง

สวัสดี Python
5

อีกวิธีคือพิมพ์คำสั่งรันเองใน Terminal (ต้องอยู่ในโฟลเดอร์เดียวกับไฟล์)

python hello.py
อ่านโค้ดในเว็บนี้ยังไง · บรรทัดสีจาง ๆ ที่ขึ้นต้นด้วย # ข้าง ๆ โค้ด คือผลลัพธ์ ที่จะเห็นเมื่อรัน ไม่ต้องพิมพ์ตาม · พิมพ์โค้ดเองทุกตัวอักษร อย่าก๊อบวาง มือจะจำ และจะได้เจอ error จริงตั้งแต่เนิ่น ๆ

0.6 ไฟล์ .py กับโหมดพิมพ์ทีละบรรทัด

ถ้าพิมพ์ python เฉย ๆ ใน Terminal จะเข้าโหมดที่มี >>> พิมพ์ทีละบรรทัดแล้วเห็นผลทันที เหมาะกับการลองอะไรสั้น ๆ

>>> 2 + 3
5
>>> exit()          # ออกจากโหมดนี้
ไฟล์ .pyโหมด >>>
บันทึกเก็บไว้ได้ไม่ได้ ปิดแล้วหาย
พิมพ์ 2 + 3 เฉย ๆไม่แสดงอะไร ต้องใช้ print(2 + 3)แสดง 5 ให้เลย
ใช้เมื่อทำโจทย์ ทำงานจริง ทุกบทในเว็บนี้ลองคำสั่งสั้น ๆ
อย่าพิมพ์ python hello.py ในโหมด >>> จะได้ SyntaxError เพราะนั่นเป็นคำสั่งของ Terminal ไม่ใช่โค้ด Python · ถ้าเห็น >>> ให้ exit() ออกมาก่อน

0.7 ปัญหาที่เจอบ่อยตอนเริ่ม

อาการสาเหตุแก้
'python' is not recognized as an internal or external command ตอนติดตั้งไม่ได้ติ๊ก Add python.exe to PATH ติดตั้งใหม่แล้วติ๊ก · หรือบน Windows ลองพิมพ์ py แทน python
พิมพ์ python แล้ว Microsoft Store เด้งขึ้นมา Windows มีทางลัดชื่อ python ที่ชี้ไป Store ติดตั้งจาก python.org แล้วปิดทางลัดที่ Settings → Apps → Advanced app settings → App execution aliases
can't open file '...hello.py': [Errno 2] No such file or directory Terminal อยู่คนละโฟลเดอร์กับไฟล์ หรือพิมพ์ชื่อไฟล์ผิด ใช้ปุ่ม ▶ ใน VS Code · หรือ cd เข้าโฟลเดอร์ก่อน
ไฟล์กลายเป็น hello.py.txt Windows ซ่อนนามสกุลไฟล์ แล้วโปรแกรมที่ใช้ต่อ .txt ให้เอง File Explorer → View → ติ๊ก File name extensions แล้วแก้ชื่อไฟล์
macOS: command not found: python macOS ใช้ชื่อ python3 พิมพ์ python3 และ pip3 แทน
'pip' is not recognized (ตอนติดตั้งไลบรารีบทที่ 14) หา pip ไม่เจอ ใช้ python -m pip install ชื่อไลบรารี
pip install สำเร็จแล้ว แต่รันได้ ModuleNotFoundError VS Code ใช้ Python คนละตัวกับที่ pip ติดตั้งให้ Python: Select Interpreter เลือกให้ตรง (หัวข้อ 0.4) แล้วติดตั้งใหม่ด้วย python -m pip install ใน Terminal ของ VS Code
กดรันแล้วไม่เห็นอะไรเปลี่ยน ยังไม่ได้บันทึกไฟล์ บันทึกก่อนรันทุกครั้ง · VS Code: เปิด File → Auto Save

พอรันได้แล้วเจอ error ระหว่างเขียนโค้ด ให้เปิด คู่มืออ่าน error · ตั้งชื่อไฟล์ห้ามซ้ำกับชื่อ module เช่น random.py, math.py (ดูเหตุผล)
